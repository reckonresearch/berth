# The Placement Holdout Protocol

The specification lives at
**[docs.reckonresearch.com/holdout](https://docs.reckonresearch.com/holdout/)**,
published under CC BY 4.0.

It is maintained in one place on purpose. A specification kept in two
locations drifts, and a drifted specification is worse than one that is only
findable in a single place.

The reference implementation is `berth/holdout.py` in this repository, and
gateway configurations for running the assignment without application code are
in [`contrib/gateway`](../contrib/gateway/README.md).
